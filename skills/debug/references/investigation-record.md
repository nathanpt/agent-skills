# Investigation Record

Use this structure only when the investigation is substantial or spans sessions. Keep short entries tied to observed evidence.

```markdown
# Debug Investigation

## Symptom

## Expected behavior

## Actual behavior

## Reproduction

## Known facts

## Unknowns

## System path and boundaries

## Hypotheses

| ID | Hypothesis | Prediction | Falsifier | Status |
|---|---|---|---|---|
| H1 |  |  |  | unverified |

## Evidence and experiments

| Experiment | Command or action | Result | Conclusion |
|---|---|---|---|

## Root-cause assessment

## Fix and verification

## Cleanup

## Remaining uncertainty
```

Allowed hypothesis states are `unverified`, `supported`, `refuted`, and `confirmed`. Do not rewrite observations to match a later theory.
